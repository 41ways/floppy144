## 한 줄

혼수상태의 주인공이 무의식 속 어둠을 **심장박동(핑)으로 밝히며** 내려가,
제세동기의 충격으로 무의식이 병원을 닮아가는 것을 지나, 문을 열고 **눈을 뜬다.**

## 핵심 규칙

| 규칙 | 내용 |
|---|---|
| 보는 법 | 걷기는 완전 무음. **클릭 = 핑** — 총알 같은 점 1,100개가 정면 반구로 퍼지고, 벽에 도탄(최대 10회)하며 에너지가 다할 때까지 난다 |
| 남는 것 | 총알이 닿은 자리에 **영구히 남는 점**(잔류 0.95). 지도는 벽뿐 — 움직이는 것은 남지 않는다 |
| 대가 | 핑이 닿은 괴물은 **핑의 발원지**로 돌진한다 → 쏘고 움직이는 것이 유일한 생존법 |
| 라이프 | 3회. 죽으면 지도를 들고 입구로. 0이 되면 **심정지 화면**(ECG 평탄화) 후 새 동굴(새 시드) |

충격 횟수(`g_shockf`)가 **현실화의 축**: uRoom(동굴→건축), uGrey(탈색), 조명, 면 등장 비율이 전부 여기 물려 있음.

## 길찾기 힌트 (구현됨)

- **가이드 펄스**: 충격 #1 이후, 심장이 주기적으로 **출구 방향 원뿔 파동**을 자동 발사. 자국은 2초 소멸(빌린 빛 규칙 공유). **문에 가까울수록 주기가 빨라짐**(비프 동반) — 심박 상승이 곧 내비게이션
- 파랑=멀리 뚫림 / 주황=가까운 벽 (거리 팔레트)
- 홀에서는 천장 패널 격자가 방향 기준

### 추가 후보 (미구현, 논의용)
- 출구 쪽 벽에만 병원 표지(EXIT 픽토그램) 실루엣
- 모니터 비프가 문 방향을 향할 때만 또렷해지는 스테레오 패닝
- 잘못된 방향으로 오래 가면 플랫라인 경고음이 스멀거림

## 결말 시퀀스

문 클릭 → **끝없는 길**(4초 강제 주행, 세계가 하얗게) → **무한 백색 방 + 전등 하나**(코드에 매달린 전구, 바닥 광원 감쇠) → **전등이 꺼짐**(1초, 완전 암전) → **눈꺼풀이 열림** → 필름 톤 병실(면광원 창, AO, 바닥 반사, ACES+그레인) → `AWAKE / BIS→100`.

## 오디오 (전부 런타임 합성, waveOut)

핑=저음 그릇(비정수 배음 5개+맥놀이) · 잔향=콤3+올패스 · 수중=1극 저역(0.055) · 풍덩 · 스트로크 · 괴물 3성부 · 제세동(차지 화인→쿵→심박 2박) · 형광 험 · 모니터 비프 · 평탄음.

## 오늘 밤 기타 수정

- 타이틀 기울어짐: 스폰 시선이 터널 방향으로 회전한 상태에서 월드축 글자를 놓아 생긴 것 → 타이틀은 항상 정면(-z)

## 알려진 러프 엣지 (테스트 후 판단)

1. 매복 12마리 난이도 미조정 — 충격 전 1.55초를 못 버틸 수 있음
2. 3단계 시각 혼합(uRoom 0.5)에서 충돌은 홀 기준이라 벽 일부 시각 관통 가능

4. 가이드 펄스가 벽 너머 문 방향을 가리킴(경로가 아니라 방위) — 백룸이 개활지라 대체로 유효
